# REGISTRA-IP

REGISTRA-IP — Registro y verificación de autoría. Proyecto de la materia Diseño de Interfaces de Usuario.

## Descripción

Este proyecto corresponde a la Práctica 1: Preparación del entorno de desarrollo.

El objetivo es configurar las herramientas necesarias para desarrollar una aplicación web utilizando React y Vite, así como gestionar el código fuente mediante Git y GitHub.

## Tecnologías utilizadas

- Node.js
- npm
- React
- Vite
- Visual Studio Code
- Git
- GitHub

## Ejecución del proyecto

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```
